# Arithmetic-Logic-Unit-ALU-using-Verilog
A Verilog HDL based Arithmetic Logic Unit (ALU) project capable of performing arithmetic and logical operations such as addition, subtraction, AND, OR, XOR, and comparison operations in digital systems.

## Overview
The Arithmetic Logic Unit (ALU) is a fundamental digital circuit designed using Verilog HDL. It performs various arithmetic and logical operations required in processors and digital systems.

This project demonstrates the implementation of RTL design and digital logic concepts using Verilog.

## Features
- Addition Operation
- Subtraction Operation
- AND Logic Operation
- OR Logic Operation
- XOR Operation
- Comparison Operations
- Efficient Digital Logic Design
- Verilog HDL Implementation

## Technologies Used
- Verilog HDL
- Digital Electronics
- RTL Design
- Xilinx Vivado 

## Software Requirements
- Xilinx Vivado 
- Verilog Simulator

## Working Principle
The ALU receives input data and control signals to perform arithmetic or logical operations. Based on the selected operation code, the circuit generates the corresponding output.
